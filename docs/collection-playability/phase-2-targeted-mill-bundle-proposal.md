# CPA Phase 2 — Contextual draw and targeted mill proposal

**Full Phase 2 release status — BLOCKED.** Guide sections 5.3 and 11 require peer-relative costs, contextual effect bundles, timing, reliability and resource constraints. This increment would explain the qualitative contribution of one supported secondary effect. It would leave full-bundle comparisons, broader functional groups, repeatability and other resources open. Production changes require approval.

## Baseline and independent expectations

The extra mill cannot be converted to a draw-equivalent value from that evidence. Time Stretch and the existing synthetic unsupported secondary effect supply negative controls. On HEAD `c58dc8c` with the existing local CPA changes, the Golden input produced `higher_mana_for_same_draw` with model `cpa-efficiency-v1` and two native draw references at `[0:16]`, one per card. On Bounty, the draw and mill use the same spell execution unit with `at_least_one_target_legal`. The mill reference at `[18:49]` is also the unit's sole `target_evidence_id`. The proposed guard closes this gap before either component can gain positive evidence through that shared resolution.

## Proposed behavior and representation

1. Restrict the increment to the verified complete sorcery shape of one fixed draw followed by one fixed mill of `Target player`. Match the shape by semantics and exact frozen source, including native draw and mill references, rather than card name. Preserve the existing pure-draw and per-activation paths. The two effects retain their one spell execution unit. Require the draw and mill uses to be supported or conditional, link to that unit and resolve to exact Oracle evidence from the same verified boundary. Require exactly one target evidence ID in the unit, bound to the mill reference and the verified player target, and keep both resolution requirements. An unsupported effect, missing or inconsistent target link, ambiguous scope or unresolved dependency suppresses positive findings for this bundle, including the draw component that depends on the same resolution. Keep the underlying evidence and expose an unresolved bundle-target limitation when the missing link caused the abstention.
2. Reuse `PlayabilityContext.strategy_ids` to express explicit intent. An explicitly selected `mill` strategy and the configured `mill_theme_mill_opponent` preference for opponent milling establish the qualitative objective. They are independently authored context inputs. Bind them to the verified mill use and exact target evidence, and record the strategy ID, preference ID and catalog fingerprint already available in provenance. An automatically enumerated strategy, an empty selection, a card tag or the word `mill` on its own supplies no such intent. The positive statement is conditional on choosing a legal **opponent** as the player target and resolving the spell. Choosing oneself is legal under the printed wording when applicable, but the opponent-mill objective provides no evidence of benefit for that choice. The profile records neither a particular player nor a claim that one is available or was selected.
3. Attach one optional `targeted_mill_assessment` to the profile. Reuse the `ExecutionUnit` link and existing evidence IDs. The assessment carries `execution_unit_id`, `mill_evidence_ids`, `target_evidence_ids`, `target_legality` (`unassessed`), `mill_contribution` (`unknown` or `conditional_benefit`), `bundle_efficiency` (`unknown`) and `model_version` (`cpa-draw-targeted-mill-v1`). Only the conditional benefit carries the catalog and explicit strategy basis. It means that milling up to the printed three cards from the chosen opponent contributes to the selected library depletion objective if the spell resolves and the effect can carry out the mill. It provides no measured impact or numeric conversion. The printed effect and target stay visible without the objective, with an unknown mill contribution. The first increment leaves bundle efficiency unknown even in the explicit mill context, since the owned peer verifies only the draw and there is no evidence comparing both effects.
4. Preserve the existing v1 draw finding for a verified bundle and compatible Brilliant Plan peer, including both native draw citations and the shared target condition. The new assessment cites the mill/target separately through that same unit. The draw-cost result remains conditional on successful resolution. At casting, there must be a legal choice for the required target. If the sole target is illegal on resolution, the spell does not resolve, so neither draw nor mill occurs. The annotation should explain that consequence while leaving actual target legality unassessed. An unknown **game-state** target is compatible with a conditional printed comparison. Missing **source evidence** for the target blocks that comparison. [Wizards Comprehensive Rules, November 6, 2026, rules 601.2c and 608.2b](https://media.wizards.com/2026/downloads/MagicCompRules%2020261106.pdf)

## Acceptance and compatibility

| Case | Expected result |
| --- | --- |
| Default or draw-focused context with Bounty and Plan owned | Same three-card draw comparison and one generic mana difference, with both endpoint refs. One spell unit, unknown mill contribution, unassessed target legality and unknown bundle efficiency. |
| Explicit `mill` context with matching configured preference | Same component comparison. Conditional qualitative benefit linked to the mill and target evidence, explicitly limited to choosing a legal opponent and resolution. No claim about self-mill, present game state or whole-bundle ranking. |
| Explicit strategy with missing or incompatible catalog preference | No conditional mill contribution. Verified printed evidence and the draw-only comparison can still be reported under the unit's resolution conditions. |
| Missing target reference, wrong target association or unverified secondary effect | No positive mill contribution or draw-cost finding for the affected bundle. Check that the unresolved source linkage is disclosed. |
| Verified printed link, sole target later illegal | The output describes both effects as unavailable in that case and never promotes the unknown runtime target status to legal. No board-state evaluator is added. |
| Time Stretch, synthetic extra win effect and existing other models | Time Stretch and the unsupported variant retain abstention. Pure draw, activation comparisons and existing bounded peer truncation retain their behavior. |

Add the optional assessment at the end of `PlayabilityProfile` and omit it from `to_json()` when absent. No input schema change is needed. The existing context ID, native evidence, execution-unit IDs, and unaffected serialized profiles retain their meaning. Annotated profiles receive new content-derived IDs, and an affected bundle that fails the new evidence guard can also change. The versioned additive field should be accepted by strict consumers before they ingest annotated profiles. Keep the existing deck artifact schema and v1 draw-finding fields. The scope of the new assessment is a single spell analysis, independent of whether the bounded peer search finds a draw peer.
